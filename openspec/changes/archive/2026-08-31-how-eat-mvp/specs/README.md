# Specs for how-eat-mvp

Capability specs are produced in the `spec` SDD phase. Each capability lives in
its own folder: `specs/<capability>/spec.md`.

Suggested capabilities (see `../proposal.md`):

- `calculations` — pure math engine + edge cases
- `calculator-form` — inputs, validation, tooltips
- `macro-sliders` — presets + linked sliders, 100% sum invariant
- `result-card` — output rendering
- `persistence-share` — localStorage + URL share
- `accessibility-responsive` — WCAG AA + breakpoints
